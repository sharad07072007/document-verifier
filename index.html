    Checksum validator

    Many official documents embed a mathematical check digit — a credit card number, an IBAN, or a passport MRZ field. Verify one here to see if the digits are internally consistent.

    This tool applies well-known, publicly documented forensic heuristics (error level analysis, OCR, metadata inspection, checksum formulas). Uploaded files are sent to the Scrutiny API backend above for analysis, then discarded unless the server is configured to retain them. Results are indicative, not a definitive determination of authenticity; no automated check is 100% foolproof, and edge cases (re-scanned originals, screenshots, low-quality photos) can trigger false flags.
